# SP Forecast — сборки

Готовый `SP Forecast.exe` (прогноз заказа запчастей) для автообновления.
Исходники — в приватном репозитории `MaxSmych/Safety-stock`.

Скачать: **Releases** → последняя версия → `SP Forecast.exe`.
Положить в папку проекта рядом с `build_order.py` и `profiles/`. Дальше программа обновляется сама.
